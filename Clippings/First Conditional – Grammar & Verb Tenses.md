## Transcript

### Introduction

**0:02** · ESL Library First Conditional What is the conditional mood in English?

**0:15** · We use the conditional mood for hypothetical situations.

**0:19** · When we don’t know if something will happen, we make a guess about the outcome.

**0:25** · What is the first conditional?

**0:27** · We use the first conditional for a possible or likely outcome.

**0:32** · This means that if a certain condition is met, the outcome will probably happen.

**0:38** · For example: If she studies hard, she will pass the test.

**0:44** · If the condition of studying hard is met, it is likely that the outcome will be passing the test.

### Sentence Patterns

**0:54** · The most common first conditional pattern is: if + present, will + verb Note that we use a comma after the “if” clause.

**1:07** · For example: If it is sunny tomorrow, we will go to the beach.

**1:13** · The “if” clause doesn’t have to start the sentence.

**1:17** · Another common pattern for the first conditional is: will + verb, if + present.

**1:26** · Note that we don’t use a comma before the “if” clause.

**1:30** · For example: We will go to the beach if it is sunny tomorrow.

### Examples

**1:39** · Let’s look at some more examples of first conditional sentences in English.

**1:45** · If he drives really fast, he will get a speeding ticket.

**1:53** · If the students do well on the test, their teacher will let them go home early.

**2:02** · If you miss the bus, you will be late for school.

**2:09** · She will be tired tomorrow if she watches TV all night.

**2:17** · The children will eat all these cookies if we don’t hide them.

**2:25** · We will be so happy if we win the game on Saturday.
