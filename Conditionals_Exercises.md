## Part 1: Zero Conditional（零条件句）

### Exercise 1A: Fill in the blanks — 来自视频的真实例句
1. If the wind _______ (blow), the trees _______ (move).
2. If I _______ (drink) coffee after 3 PM, I _______ (not/sleep) at night.
3. If you _______ (leave) ice cream in the sun, it _______ (melt).
4. People _______ (get) hungry if they _______ (not/eat).
5. If you _______ (push) this button, the lights _______ (come) on.
6. If you _______ (put) a stone in water, it _______ (sink).
7. If you _______ (heat) water, it _______ (evaporate).
8. If I _______ (be) sad, I _______ (eat) chocolate.
9. People _______ (die) if they _______ (not/drink) enough water.
10. If dogs _______ (get) angry, they _______ (growl).

### Exercise 1B: Zero Conditional with Imperatives（祈使句）— 来自视频
1. If Phil _______ (call), _______ (not/answer) the phone.
2. If you accidentally _______ (drop) some trash, _______ (pick) it up.
3. When you _______ (get) home, _______ (call) me.
4. If she _______ (ring) the doorbell, _______ (tell) her to go away.
5. _______ (text) me if you _______ (get) lost.

### Exercise 1C: IF vs WHEN — 来自视频
1. _______ you get home, call me. (说话人期待对方回家，用if还是when?)
2. _______ you put a stone in water, it sinks. (永远如此，if和when都可以吗?)
3. _______ you get home late, call me. (说话人不确定对方是否会晚归，用if还是when?)

## Part 2: First Conditional（第一条件句）

### Exercise 2A: Fill in the blanks — 来自视频的真实例句
1. If we _______ (not/leave) soon, we _______ (miss) our train.
2. If I _______ (be) late for work again, I _______ (might/lose) my job.
3. When you _______ (tell) Dan the news, he _______ (be) going to faint.
4. If she _______ (study) hard, she _______ (pass) the test.
5. If it _______ (be) sunny tomorrow, we _______ (go) to the beach.
6. If he _______ (drive) really fast, he _______ (get) a speeding ticket.
7. If the students _______ (do) well on the test, their teacher _______ (let) them go home early.
8. If you _______ (miss) the bus, you _______ (be) late for school.
9. She _______ (be) tired tomorrow if she _______ (watch) TV all night.
10. The children _______ (eat) all these cookies if we _______ (not/hide) them.

### Exercise 2B: Unless = If...not — 来自视频
1. If you _______ (not/get) an invitation, you _______ (not/can) come to the party.
   → _______ you get an invitation, you can't come to the party.
2. If this program _______ (not/load), I _______ (not/be) able to finish my work.
   → _______ this program loads, I won't be able to finish my work.
3. If we _______ (not/leave) now, we _______ (might/miss) the train.
   → _______ we leave now, we might miss the train.

### Exercise 2C: First Conditional with Modals — 来自视频
1. If we don't leave now, we _______ (might/miss) the train.
2. If you study hard, you _______ (could/pass) the exam.
3. If I see my boss, I _______ (shall/ask) her.
4. If it gets colder, we _______ (should/light) a fire.
5. I _______ (be/able to) finish my painting, if I _______ (have) time.

### Exercise 2D: Zero vs First — 来自视频的对比练习
1. If I _______ (have) time, I _______ (work) out. (general habit → Zero)
2. If I _______ (have) time, I _______ (work) out. (specific future plan → First)
3. If I _______ (listen) to music on my phone, I _______ (use) headphones. (always → Zero)
4. If I _______ (listen) to music on my phone, I _______ (use) headphones. (specific situation → First)
5. If I _______ (listen) to music on my phone, I _______ (use) headphones. (but I never do → Second)

## Part 4: Third Conditional（第三条件句）

### Exercise 4A: Fill in the blanks — 来自视频的真实例句
1. If I _______ (study) harder, I _______ (pass) my exam.
2. If I _______ (study) harder, I _______ (pass) my exam. (口语缩略形式: If I'd...)
3. I _______ (make) more food if I _______ (know) Karen and Paul were coming.
4. If I _______ (not/trip), I _______ (could/win) the race.
5. If we _______ (leave) earlier, we _______ (not/arrive) late.
6. You _______ (not/be) so tired, if you _______ (go) to bed earlier.

### Exercise 4B: Reality check — 来自视频
**根据视频中的例句，写出实际情况（Reality）：**

1. If I had studied harder, I would have passed my exam.
   → Reality: I _______ (not/study) hard, so I _______ (not/pass) my exam.

2. I would have made more food if I had known Karen and Paul were coming.
   → Reality: I _______ (not/know) they were coming, so I _______ (not/make) more food.

3. If I hadn't tripped, I could have won the race.
   → Reality: I _______ (trip), so I _______ (not/win).

## Part 5: All Four Conditionals — 同一场景对比（来自Arnel视频）

### Exercise 5A: "If we drive, we get there faster" — 四种条件句
**根据语境选择正确的条件句类型并填空：**

1. (Zero) My husband and I work in the same office. Sometimes we walk, sometimes we drive.
   If we _______ (drive), we _______ (get) there faster.

2. (First) Tomorrow I want to visit my parents. We can take the four o'clock train.
   If we _______ (drive), we _______ (get) there faster.

3. (Second) My husband and I don't have a car. It would be impossible to drive.
   If we _______ (drive), we _______ (get) there faster.

4. (Third) We got to my parents' house 30 minutes late. The train was 30 minutes late.
   If we _______ (drive), we _______ (get) there faster.

### Exercise 5B: "If I listen to music on my phone" — 三种条件句对比
1. (Zero) I always listen to music on my phone. When I do, I use headphones every time.
   If I _______ (listen) to music on my phone, I _______ (use) headphones.

2. (First) I'm gonna take a break. I might listen to some music. (specific situation)
   If I _______ (listen) to music, I _______ (use) my headphones.

3. (Second) I never listen to music on my phone, I like the radio. (imaginary)
   If I _______ (listen) to music on my phone, I _______ (use) headphones.

## Part 6: Mixed Conditionals（混合条件句）

### Exercise 6A: Past condition → Present result — 来自视频
1. If I _______ (study) German in school, my German _______ (be) better now.
   → Reality: I _______ (not/study) German, so now my German _______ (not/be) very good.

2. If you _______ (not/break up) with me, we _______ (still/be) together.
   → Reality: We _______ (break up), so we _______ (not/be) together now.

3. If you _______ (put) your coat on, you _______ (not/be) sick.
   → Reality: You _______ (not/put) your coat on, so now you _______ (be) sick.

### Exercise 6B: Present condition → Past result — 来自视频
1. If I _______ (be) rich, I _______ (buy) that coat.
   → Reality: I _______ (not/be) rich, so I _______ (not/buy) the coat.

2. If I _______ (live) closer to you, I _______ (come) to your birthday party.
   → Reality: I _______ (not/live) close to you, so I _______ (not/go) to your party.
